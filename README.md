# ollamark-webpage-summarizer-ollama

[![License](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Version](https://img.shields.io/badge/Version-1.0.0-blue.svg)](https://example.com)

**Lazy reader, lazy AI** – A Chrome extension that summarizes any webpage using a local Ollama model, with configurable model selection and system prompt.

## Features

- Dark-themed interface for optimal readability
- Summarizes any webpage using local Ollama models (Gemma, Qwen, etc.)
- Configurable model selection and system prompt
- Built with Chrome Manifest V3 for security and performance
- Lightweight and efficient for quick summaries

## Tech Stack

- **Chrome Extension** (Manifest V3)
- **Ollama** (Local AI model integration)
- **HTML/CSS/JavaScript** for frontend
- **Markdown** support for structured output

## Getting Started

### Installation

1. Open Chrome and go to `chrome://extensions/`.
2. Enable **Developer Mode** by toggling the switch in the top-right corner.
3. Click **Load unpacked** and select the folder containing the extension files.
4. The extension will be installed and ready to use.

### Usage

1. Navigate to any webpage.
2. Click the extension icon in the toolbar.
3. Select a model from the available options.
4. View the generated summary in the popup.
